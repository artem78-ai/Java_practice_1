# Матрицы комплексных чисел

Выполнил: Петров Артём Олегович, группа: 25КНТ-6
Консольное приложение на Java для работы с матрицами, элементы которых являются комплексными числами. Практическая работа по Java.

## Возможности

| Операция | Описание |
|---|---|
| Сложение | `A + B`, матрицы должны быть одного размера |
| Умножение | `A * B`, число столбцов `A` равно числу строк `B` |
| Деление | `A / B = A * B⁻¹`, `B` должна быть квадратной и невырожденной |
| Транспонирование | Строки и столбцы меняются местами |
| Определитель | Только для квадратных матриц |

Результат каждой операции становится **текущей матрицей**, поэтому операции можно соединять в цепочки, например `(A + B) * C`, без повторного ввода данных.

## Структура проекта

```
.
├── ComplexNumber.java   # комплексное число и арифметика над ним
├── ComplexMatrix.java   # матрица комплексных чисел и операции над ней
├── Main.java            # консольный интерфейс (меню)
└── README.md
```

- **`ComplexNumber`** хранит действительную и мнимую части. Реализует сложение, вычитание, умножение, деление и смену знака. Объекты неизменяемы: каждая операция возвращает новое число.
- **`ComplexMatrix`** хранит двумерный массив комплексных чисел. Реализует все операции из таблицы выше и проверяет размеры матриц, бросая понятные исключения.
- **`Main`** запрашивает матрицу, показывает меню и выводит результат.

## Как пользоваться

1. Введите размеры первой матрицы и её элементы.
2. Каждый элемент вводится как **два числа через пробел**: действительная и мнимая часть.
   Например, `3 -2` означает `3 - 2i`.
3. Выберите операцию в меню.
4. Для сложения, умножения и деления программа запросит вторую матрицу `B`.
5. Результат станет текущей матрицей, с ним можно продолжать работу.

Дробные числа вводятся через точку: `1.5`.

### Меню

```
1 - Сложить с матрицей B
2 - Умножить на матрицу B
3 - Разделить на матрицу B
4 - Транспонировать
5 - Вычислить определитель
0 - Выход
```

### Пример

Определитель матрицы `[[1, 2], [3, 4]]` с нулевыми мнимыми частями:

```
Строк: 2
Столбцов: 2
Элемент [0][0]: 1 0
Элемент [0][1]: 2 0
Элемент [1][0]: 3 0
Элемент [1][1]: 4 0

Выбор: 5
Определитель: -2.00 + 0.00i
```

Для каждой операции (сложение, умножение, деление, транспонирование, вычисление определителя) были проведены тесты. Результаты тестов приведены в папке [tests](tests/).

## Как это работает

- **Определитель** вычисляется рекурсивно разложением по первой строке.
- **Обратная матрица** строится через алгебраические дополнения: `A⁻¹ = (1 / det A) · adj(A)`, где `adj(A)` — транспонированная матрица алгебраических дополнений.
- **Деление матриц** сводится к умножению на обратную матрицу.
